## 一起玩

把散落的零件拼成 DJ 和 YW，或点「我太懒了」帮忙拼好。唤醒之后，陪他们漫步、牵手、亲脸颊，或跳一支舞。

手机和电脑都可以玩，支持中英文。想更有气氛，就打开右上角的音乐。
