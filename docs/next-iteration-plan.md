## 必须保留的避障约定

- 所有平面行走继续走同一套障碍登记、路径规划与扫掠检查；不另写绕花排斥力，不用直接修改世界坐标绕过导航。
- 保留「原地放下 → 等落稳 → 附近清场 → 完整动作／组合 → 返回原落点拾取」。连续动作只拾放一次，取消也走同一恢复流程。
- 花园、桌椅、落地道具及正在使用的场地需要一致的占位信息；分别记录实体障碍与临时预留区，明确持有者、释放时机和本场景的有意接触例外，避免角色被自己的预留区挡住。
- 选场地检查完整动作范围、进退场路线与拾取通路，不能只检查终点。拥抱、亲亲、交接仍允许声明过的接触，其余阶段不放宽全局安全距离。
- 找不到安全位置时有限次重选；仍无解则保留已有状态，轻提示后安全返回拾取，不瞬移、不忽略障碍，也不无限等待。
- 完成、取消、重拼都清理临时模型、障碍、预留区和延迟音效。已种下的花只在重拼／刷新时清空。
- 保留当前手机默认取景与手动镜头控制；新增场景只调整必要的构图范围，不覆盖用户手动操作。

## 第一批：花园

1. 将单花状态扩展为带稳定 ID、位置、花型、颜色与占地半径的列表；障碍由列表统一生成，先验证 1 → 3 → 5 朵的避让与清理。
2. 为五种不同颜色／积木花型定义实际尺寸，按包围体积留人物净空；登记标准部件来源与许可，原创部分另列。
3. 随机选点前检查边缘、已有花、四件落地道具，以及两人种花站位和可达路径。五次种植不能堵死后续办公进退场或最大的互动区域；预留空间通过可行性检查落实，不能事后缩小碰撞体补救。
4. 未满五朵继续种新花；满五朵将同一入口改为「陪花跳支舞」，在已有花中随机选取并避免连续重复。围绕花的舞步使用安全站位和动作范围，不穿过花心。
5. 正式种下作为持久化到当前会话的提交点；此前取消收回花苗，此后取消保留花。刷新／重拼清空，暂不加跨刷新存档。

验收：五朵互不重叠且外观可分辨；拥挤与边缘布局仍能漫步、跳舞、开启另外两个场景并拾回道具；种下前后取消、满额重复选择、重拼都没有重复花或残留障碍。

## 第二批：加一会儿班

流程：共同清场 → 两人让出家具入口 → 桌椅电脑进场 → YW 入座 → DJ 小跑陪伴／短暂停步看她 → DJ 停到退场安全位 → YW 起身离座 → 家具退出 → 两人拾回原道具。

- 先登记桌椅工作占地、移动中的家具占地与进退场通道，再设计绕桌路径；保留入座和操作电脑的局部接触例外。
- 跑动路线检查桌椅、坐着的 YW、全部花及落地物。使用共享导航经过安全控制点，不用圆周公式直接推进人物位置。
- 空间足够时跑一圈；空间不足时采用安全的局部往返加停步，不能强行从椅背与花之间挤过去。进场前就确认至少有一条可执行的陪伴路线。
- 取消顺序优先安全：DJ 停稳让路 → YW 离座 → 家具退出 → 释放占位 → 拾取；家具不能在人身上直接退场。

验收：空台与五花布局都能完成；家具移动时不撞人，DJ 不穿桌椅／YW／花；进场、入座、跑动、起身和退场逐阶段取消均能恢复漫步及四件手持物。

## 第三批：送你一只包

先完成动作再细化材质，避免同时改变骨骼、握持和模型尺寸导致问题难以定位。

1. **动作流程**：清场 → DJ 藏包靠近 → YW 歪头 → DJ 转身藏一下 → 双手递出与小爱心 → YW 握稳后交接 → YW 挎包左右展示、DJ 看着她 → 收包 → 亲脸颊 → DJ 羞羞 → 统一拾取。
2. **持有状态**：包始终一个实例；交接前属于 DJ，握稳后属于 YW，收好后不再占用手部。双手展示采用主握持点和辅助对位，不复制模型；取消根据当前持有者收好。
3. **外观**：暂按暖棕 Birkin 方向，细化梯形包身、双提手、翻盖、皮带、金色扣件、锁与钥匙皮套、缝线和克制的皮革质感；配橙色盒与深棕缎带。真实礼物款式未确认，保留模型替换接口，不标为官方 LEGO 联名件。
4. **礼盒与声音**：先确定盒子的出场、放置和收回时机，并将其纳入临时占位；开盒／扣件声音只在真实事件触发。取消与重拼清理礼盒、爱心和待播放声音。

验收：身体自然遮挡藏包；递包、转身和展示不穿模；包随正确的手移动，亲亲前已收好；在偏离原点的空地与五花环境中正常交接。所有阶段取消后无包／盒／爱心残留，手机取景能覆盖完整动作。
