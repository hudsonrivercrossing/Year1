- **加班**：YW 单独入座工作；DJ 绕桌小跑、停步看她，拥挤时采用安全的局部往返。家具退出前两人先让路。
- **花园**：最多五朵不同颜色与刚性积木组合的花；随机安全选址，满额入口改为“陪花跳支舞”，不连续选同一朵。重拼／刷新清空，已种下的花在取消后保留。
- **送包**：打开橙色礼盒取包并收好礼盒 → 藏包靠近 → YW 歪头 → DJ 转身藏一下 → 双手递出与小爱心 → YW 握稳后单实例交接 → 左右展示 → 收包 → 亲脸颊 → DJ 羞羞 → 统一拾回原道具。暖棕色包参考 Birkin 家族的梯形轮廓、双提手、翻盖、皮带和金色扣件；真实礼物款式未确认，不标作官方联名件。

## 1. 加一会儿班

**完整动作**：先放下原有四件手持物 → 两人让出空地 → 桌子、两把椅子与电脑从工作台边缘进入 → 两人各自走到座位 → 转身坐好 → 轻轻敲键盘、看看屏幕和对方 → 起身让开 → 桌椅电脑全部退回边缘并回收 → 回原处拾起杯子、甜筒与雪杖 → 漫步。

- 以同一组家具的生命周期验证入场、使用、退场与清理，先完成一个闭环，再做下一种高级动作。
- 坐姿按实际座面和积木腿部几何定位；保留刚体积木关节，不添加软膝盖或软肘。
- 场外明确为工作台边缘，360° 旋转时依旧成立。先安排人物让路，再移动家具，避免从人身上穿过。
- 轻键盘声与到位声跟实际事件走；保持低音量，不盖住音乐。
- 手机取景同时容纳两人和桌椅。用户手动旋转后继续保留镜头控制权。
- **取消**：坐下时先起身；家具退出前先让开。任一阶段取消，都完成必要退场和清理，再返回拾取原道具，最后恢复漫步。

## 2. 种一朵花

**完整动作**：先放下手持物 → DJ 从身侧拿出小花苗 → YW 一起靠近选好的位置 → 两人轮流弯腰放好、扶正 → 花用标准积木逐块组成／开放 → 并肩欣赏一会儿 → 返回拾取原道具。

- “掏出来”用身体遮挡与手部挂点实现；没有可以真正打开的口袋，不需要布料模拟。
- 花茎、花瓣和小底座优先选许可明确的标准 LEGO 模型，不拉伸网格模拟生长。
- **已采用的保留规则**：最多一朵纪念花；再次选择时照料同一朵；“再拼一次”清除。刷新不保留，首版不增加存档系统。
- 如保留花，需要登记占位，让漫步和后续家具进出绕开它。放置前取消不留下半朵花，放置后取消保留完整对象或按统一规则回收。

## 3. 送你一只包（DJ → YW）

**完整动作**：先放下手持物 → 两人面对面 → DJ 从身后拿出包 → 双手展示 → YW 伸手接过 → 确认握稳后 DJ 松手 → YW 开心地看一看、轻轻展示 → DJ 回应 → YW 把包收好 → 返回拾取原道具。

- 叙事中是爱马仕礼物；本版采用暖棕色结构包。优先用标准 LEGO 包体或标准砖搭配原创扣件装饰，保留资产来源，不把原创外观称为官方联名件。
- 包只有一个实例，交接时保留世界位置与朝向；接过的一方确实握稳后才转移所有权，不能同时出现两个包或突然跳到手里。
- 轻音效在接过和展示时发生，爱心点到为止，继续使用现有暖纸色和小音量体系。
- **已采用的收好方式**：展示后 YW 将包收到身侧，借身体遮挡隐藏并回收本次场景道具，随后再拾起原甜筒和雪杖。若希望包长期留下，则另设唯一展示位置和占位规则。
- 取消发生在交接前，由 DJ 收回；交接后由 YW 收好。之后清理场景并恢复原有手持物。

## 共用能力与验收

1. 小剧场根节点、道具挂点、占位、所有权和清理集中管理，只有一个高级场景运行。
2. 复用“整场开始只放下一次，结束／中断后统一返回拾取”的现有流程，组合步骤中不重复拾放。
3. 每阶段记录进入、使用、离开和取消规则；重新拼装能清空家具、花、包、临时爱心、占位和待触发声音。
4. 入口归入现有轻量菜单的一组“小小生活 / Our little life”，“生活”页签只放这三个高级动作，不增加首页按钮。
5. 中英切换不重启动作；近远不同位置、360° 旋转、手机视口和连续重播都要检查。
6. 验收先看角色与道具是否对位、是否穿插，再看事件音效、取消路径、复位以及是否遗留实例。浏览器模拟通过后，仍需实体手机确认触摸、性能和声音。

实现顺序：加一会儿班的完整闭环 → 复用道具管理做种花 → 单实例交接做送包。后两项顺序可以在第一项完成后再决定。
