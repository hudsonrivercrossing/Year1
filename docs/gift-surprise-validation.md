# 送包小惊喜验收

DJ 打开橙色礼盒取包、收好盒子，再藏包靠近；YW 歪头，DJ 转身藏一下、双手递出；YW 握稳后单实例交接，左右展示并收好包，再亲脸颊、DJ 羞羞，最终统一拾取原道具。

包的主握持点随真实手掌移动；辅助手在递出阶段只计算一次关节对位，避免每帧求解带来手机负担。交接保持位置与朝向，持有者只由 DJ 转到 YW 一次。展示时转向能看到正面，礼盒不会一直挡在人物后面。开盒、交接、收扣、亲亲和羞羞分别触发很轻的事件音效。

当前包为正式 LDraw 93091 标准手提包，保持 .035 场景单位/LDU，不拉伸；暖棕色为虚拟配色。爱马仕赠礼故事保留在中英文文案里，不称作官方联名或真实品牌产品模型。礼盒采用 3021、3010、3005、3069b 组合成空心盒与可移开的盒盖，十字装饰也是标准瓷砖；小爱心仍为原创几何。

礼盒内部净空 1.4 × 1.68 × .7，包外包络约 1.333 × 1.138 × .681，确认可容纳。先完全开盖、竖直提包越过盒壁，再旋转并移向手掌。盒盖的动画支点为虚拟支点，不冒充实体铰链结构。礼盒和开盒站位均收进原有 3.4 半径的清场范围，完整盒体障碍沿用共享导航；保留原放下道具／避障／拾回事务。共享导航和逐阶段取消均纳入程序回归。
