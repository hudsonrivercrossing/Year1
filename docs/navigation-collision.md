# 人物避让与互动空地

本轮修复的原因：旧排斥力只存在于漫步分支，靠近、场景站位与返回拾取直接沿直线移动；原地开始互动时，动作位置又与四件落地道具重叠。

## 统一移动

- 所有漫步、靠近、离开、生活场景与返回拾取共用 `src/navigation.ts` 的可见图路径和每帧扫掠检查。
- 花按底座占地登记圆形障碍；落地杯子、甜筒和雪杖从真实物理姿态投影成胶囊。倒下的长雪杖保留长条占地，不能当作一个小点。
- 人物互为动态障碍；行走时保持分离，携带道具时留更大净空。拥抱、亲脸颊、并肩等声明过的贴近动作保留各自的接触距离。
- 初始已重叠时缓慢分离。脚边刚落下的物件允许单向走出；一旦离开，同一物件恢复阻挡，不能穿回。

## 动作事务

先原地放下四件道具 → 等落稳并选择附近空地 → 两人绕障走到各自站位 → 执行动作／整条组合 → 统一返回拾取。

选地优先短步行距离，避开花、落地物件和边缘；基本互动预留动作范围，默认镜头里尽量让两人都可见。加班还检查桌椅的占地和前后两种家具进场路线，使用最近的可用区域。种花位置也避开落地物件；再次照料已有花时，在其周围选择空站位。

取消移动准备阶段也进入同一拾取事务。过早取消时先等物件落稳，再计算拾取站位；原本两人位置太近时，选择其附近分开的站位，保留原始落点，不移动地上的物件。

## 验证

- `check-navigation.mts`：直线穿花／长杖回归、100 条固定种子路径的逐帧扫掠与位移、交换站位、附近互动空地与办公进场。
- `check-collision-browser.js`：真实浏览器绕花交叉行走，极近距离／边缘发起拥抱，清场距离、返回四件道具和移动后的办公场景。
- `check-collision-cancel.js`：两个原始位置几乎重叠，刚放下道具立即取消，仍能全部拾回；该用例曾在修复前卡在返回阶段。
- 原有高级动作时间线、非原点交接、逐阶段取消、手持物物理回归，以及 `/Year1/` 生产包继续检查。

这是运动体积和占地避让；花的扶正、手部交接、拥抱及入座属于有意接触。没有声称采用逐三角形人体碰撞或实体手机验收。开发版的确定性场景夹具与状态检查在生产构建中移除。
