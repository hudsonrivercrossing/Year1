## 动作与道具

- 牵手、击掌、招手、并肩停留、坐一会、等待六项已逐项运行。坐姿身体高度按实际腿部最低点计算，中途取消也保持地面间隙。
- 完整运行跳舞 → 牵手 → 并肩停留，以及漫步 → 等待 → 招呼 → 靠近 → 拥抱。顺序正确，整段开始只释放一次，段间始终四件在地上。
- 结束后返回原释放位置、俯身分别拾回四件道具；取消靠近、取消拥抱、取消坐姿、拾取中重新拼装、再次引导拼装和重新装备均通过。
- 动作结束后姿态高度、腰部、队列和临时爱心复位。拾取完成前不启动新的动作，避免遗留道具。
- 使用真实标准件网格的场景/物理测试：405 帧完成远处返回拾取，最大帧间位移约 0.0801 场景单位；实际碰撞回调、步态/斜握过渡地面间隙、真实握持点、重置后原手部子节点数量均通过。
- 1,200 次固定随机种子选择验证：随机小互动避开最近三项动作，随机组合避开最近两项；小候选池也可正常退化选择。
