# 五朵花园：第一批验收

新增五种颜色与刚性积木花型，最多五朵；共享导航避让所有已种下的花。随机选址检查边缘、落地物、站位，以及未来办公进场和基本互动空间。满额入口改为「陪花跳支舞」，避开刚选过的花。

已验证：

- `check-navigation.mts`：原有 100 条导航路径、扫掠检查、长杖绕行与办公进场基线通过。
- `check-garden.mts`：20 组固定随机布局，共 100 次种植；每次仍有办公进场及互动空间；五种颜色、满额不连续重复、重拼清理、拥挤时不强行选址通过。
- `check-life-scenes.mts`：原有三个场景完成与逐阶段取消通过；新增五次种下前取消不提交、种下后取消保留，以及清空全部障碍检查。
- `check-garden-browser.js`：390×844 实际浏览器连续种五朵，每次恢复四件原手持物；满额两次选花跳舞不连续重复，取消后仍保留五朵；320px、430px 与横屏菜单边界及键盘切页通过；重拼清空花园与正在展示的包，无浏览器异常。
- `npm run build` 通过；保留既有 Three.js 分包体积提示。

浏览器结果位于忽略目录 `output/playwright/check-garden-browser-garden-dev.json`，逐次种花截图同目录。尚未声称实体手机验收，也尚未重新发布。本记录是第一批检查，后续办公占地扩展后需要再次运行相关布局和浏览器回归。
