# Recreated minifigure shirt prints

These four PNGs are **original procedural redraws**, produced by
`scripts/prepare_portrait_prints.py`. They are not photographs, scans, or official
LDraw printed torso models. The unmodified standard LDraw 973 geometry remains
the structural part; the redraw is a replaceable front/back print layer.

Reference identification from the anniversary photo and catalog comparisons:

- DJ: [973pb5102c01](https://www.bricklink.com/v2/catalog/catalogitem.page?P=973pb5102c01), light blue Fair Isle sweater.
- YW: [973pb3541c01](https://www.bricklink.com/v2/catalog/catalogitem.page?P=973pb3541c01), white torso with six thin red stripes.

Pattern layout is approximate; stitch geometry, exact ink contours and colour
matching remain interpretations. Hair, YW face and hand props are separately
tracked in TODO.md. LDraw geometry attribution remains in `/ldraw-source`.
